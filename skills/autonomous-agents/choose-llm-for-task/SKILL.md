Find the task type in the routing table below. Take the top-3 picks **in order** — try 1st, degrade to 2nd/3rd only if that harness is capped, unavailable, or scarce (see budgets). Cross-check the per-model cheat sheet and rules of thumb before committing to a scarce or costly pick.

## Per-model cheat sheet

**Claude Code**
- `claude-opus-5-5` — Default for hard work (22 Sep 2026). AA Intelligence 58 (new high), TB4.0 59.6% ties Astra, HLE 61.4%, SciCode 66.9%, AA-Briefcase Elo 1822. $4/$20, cache reads $0.20 (60% below Opus 5), 1M ctx, >30% faster than Opus 5. Max effort ~119k output tokens/task — drop effort before escalating. Fable-class cyber/bio safeguards. Best behavioral audit Anthropic has published.
- `claude-fable-5-1` — Prior SOTA; now the fallback when Opus 5.5 token burn dominates or Claude quota favors the $10/$50 lane you already pay for. Cache reads $0.25. OSWorld 77.9%, AutomationBench 31.4%. Vuln discovery OK, not exploit-dev. `claude-mythos-5-1` = same model, Glasswing-only.
- `claude-opus-5` — Superseded by Opus 5.5 — avoid. Was $5/$25.
- `claude-sonnet-5-5` — Fast Claude lane (28 Sep). $2/$10, cache reads $0.20, cache writes $2.50, 1M ctx, ~92–139 tok/s. Pin **high** (AA index 47, ~$1.08/task, ~94 tok/s). Medium is the Claude Code default and scores 41. Max scores 56 at ~$7.62 and ~193k out — Opus xhigh is the same 56 at $3.46. AA TB4.0 at max is 64% vs Opus 60%. Cyber safeguards fall back to Sonnet 5 on high-risk cyber. `claude-sonnet-5` superseded — avoid.
- `claude-haiku-5-5` — Claude scout (shipped 7 Oct 2026). $0.10/$0.50 and cache reads $0.01 up to 100k input; above 100k the request is $0.50/$2.50 and cache reads $0.05. 1M ctx, 128k max out. Reasoning stays on; default effort is medium — pin medium for scouts, never max (~162k out/task). Same short-prompt sticker as GPT-6 Luna and the stronger of the two under 100k; Luna wins once the prompt crosses 100k (see scout row). Tokenizer counts ~30% more tokens than Haiku 4.5 on the same text. In Claude Code, the `haiku` alias is 5.5 from v2.1.293. Also on OpenCode Go at $15/mo (~3.85k req/5hr) — use Claude Code, not Go. `claude-haiku-4-5` superseded — avoid ($1/$5, 200k).

## Rules of thumb

- Prefer free/flat-rate lanes (GLM-5.3 via Pi, OpenCode cheap models) before spending on metered API (Grok CLI, Gemini) or scarce quota.
- Light scouts, lookups, scaffolds: **Haiku 5.5 and GPT-6 Luna are the two scout models.** Under 100k tokens, Haiku 5.5 at medium. At or over 100k, or a growing agent history, Luna. Non-sensitive mass scouts stay on Muse. Live-source scouting stays on Grok CLI. Do not spend OpenCode Go quota to reach Haiku or Luna.
- For live or recent-source work (what's new, who said it, which docs/posts to trust): **Grok CLI + grok-4.7, effort high.** Web + X search is the differentiator — scope there, then hand off. xhigh burns ~81k out/task and can cost more than Astra. Do not use Luna for this lane; it does not search X.
- Escalate exactly one tier after a cheaper pick fails twice — don't jump straight to the most expensive model on first friction. A short Haiku 5.5 scout fails twice → gpt-6.1-sol at medium, not Haiku max. Luna fails twice → gpt-6.1-sol at medium, not xhigh and not Astra. Sol medium fails twice on coding → xhigh, not max. Sol fails on science, security, or review → Astra. Opus 5.5 max burns tokens → drop effort before jumping to Fable or Astra. Sonnet 5.5 max is not a cheaper Opus. A capped Opus+Astra hard task → one Kimi K3.1 Pro shot, not a K3 retry.
